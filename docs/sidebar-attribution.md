# Sidebar

The sidebar primitives in `react-app/src/components/ui/sidebar.tsx` are adapted from Manu Arora's Sidebar, published under the MIT License on 21st.dev / Aceternity UI.

- Component: https://21st.dev/@manuarora700/components/sidebar
- Upstream: https://ui.aceternity.com/components/sidebar
- Registry: https://ui.aceternity.com/registry/sidebar.json

Adaptations include React Router links, explicit desktop collapse, an integrated application frame, reduced-motion support, and a Radix dialog for accessible mobile navigation.
